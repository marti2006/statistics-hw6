Contingency tables, independence and Pearson’s χ² test

Given a bivariate categorical dataset (X, F), we build the contingency table programmatically from the raw records, derive marginal and conditional distributions, compute the frequencies expected under independence, and test independence with Pearson’s χ² statistic and its p-value. Everything below is computed live in the browser by the code shown in §7.

1Independence: probability and statistics

The concepts the computations rely on.

1.1 Independence of events

In a probability space (Ω, 𝒜, P), two events A and B are independent if

P(A ∩ B) = P(A) · P(B).

When P(B) > 0 this is equivalent to P(A | B) = P(A): knowing that B occurred does not change the probability of A. Independence is a property of the probability measure, not of the events as sets. It is not the same as being disjoint: two disjoint events with positive probability are always dependent, because if one occurs the other cannot.

1.2 Independence of random variables

Two discrete random variables X (values x1,…,xr) and Y (values y1,…,yc) are independent iff the joint probability mass function factorises into the product of the marginals for every pair of values:

πij = P(X=xi, Y=yj) = πi· · π·j   ∀ i, j,      where  πi· = Σj πij,  π·j = Σi πij.

Equivalently, all conditional distributions of Y given X = xi are identical, and equal to the marginal of Y: P(Y=yj | X=xi) = π·j for every i. The relation is symmetric: if Y does not depend on X, X does not depend on Y either. Independence implies zero covariance (for numerical variables), but zero correlation does not imply independence, since it captures only linear dependence.

1.3 The empirical counterpart: contingency tables

On a sample of n units, the contingency table collects the absolute joint frequencies nij, i.e. the number of units with X = xi and F = yj. From it we get:

  • marginal frequencies: ni· = Σj nij (row totals) and n·j = Σi nij (column totals), plus their relative versions ni·/n, n·j/n;
  • conditional frequencies: the row profiles f(yj | xi) = nij/ni· and the column profiles f(xi | yj) = nij/n·j.
Statistical (empirical) independence. X and F are perfectly independent in the sample if all row profiles coincide (and therefore equal the marginal profile of F), which is the same as nij = ni· n·j / n for every cell.

The quantities

ñij = ni· · n·j / n

are the expected (theoretical) frequencies under independence. They are the maximum-likelihood estimates of nπij under H0, obtained by plugging the observed marginals into the factorised model of §1.2. With real data we never observe exact equality, so the question becomes how large the gap between nij and ñij has to be before it stops looking like sampling noise.

1.4 Pearson’s χ² statistic and test

χ² = Σi=1r Σj=1c ( nij − ñij )² / ñij

χ² ≥ 0, and it equals 0 iff the sample is perfectly independent. Its maximum is n·(min(r,c) − 1), which motivates the normalised index Cramér’s V = √( χ² / (n(min(r,c)−1)) ) ∈ [0, 1]. V measures the strength of association and, unlike χ², does not grow with sample size.

Test. H0: πij = πi·π·j for all i, j (independence) against H1: at least one cell violates the factorisation. Under H0 and for large n, χ² is asymptotically distributed as a chi-square with

ν = (r − 1)(c − 1)   degrees of freedom

(rc − 1 free cell probabilities minus (r − 1) + (c − 1) estimated marginal parameters). The p-value is p = P(χ²ν ≥ χ²obs) = 1 − Fχ²ν(χ²obs), computed here through the regularised upper incomplete gamma function Q(ν/2, χ²obs/2). We reject H0 at level α if p < α, equivalently if χ²obs > χ²ν, 1−α.

Assumptions. Units are independent of each other (simple random sampling), each unit falls in exactly one cell, and the expected counts are large enough for the asymptotic approximation to hold. The usual rule of thumb (Cochran) is ñij ≥ 5 in at least 80% of cells and none below 1; otherwise merge categories or use an exact or permutation test (§6). The Pearson residuals eij = (nij − ñij)/√ñij (with Σeij² = χ²) show which cells drive the result; |eij| > 2 is a common flag.

7Interpretation and discussion

7.1 Titanic: what the test does and does not say

For Class × Survived the result is unambiguous: χ² ≈ 190.4 on 3 degrees of freedom, with a p-value of order 10−41 and every expected count well above 5. The hypothesis that survival was independent of class is rejected at any reasonable level. The residuals show where the dependence lies: first-class passengers survived far more often than independence would predict (e ≈ +9.6), while third class and crew survived less (e ≈ −3.3 and −4.4). Cramér’s V ≈ 0.29 indicates a moderate association, so class is clearly not the whole story.

It is tempting to conclude that being in first class caused higher survival. The test does not license that conclusion. The stratified tables below repeat the same analysis separately for men and women.

Two things stand out. First, sex is strongly associated with survival (the “women and children first” protocol), and the class groups have very different sex compositions: the crew is about 97% male, while first class is about 45% female. Part of the marginal Class–Survived association is therefore the effect of sex acting through the composition of each class, which makes sex a confounder. Second, within each sex the association with class is still there, but its shape changes: among women the gap is between first/second class (97%, 88%) and third class (46%), while among men first class (34%) stands apart from all the others. Some comparisons even reverse once we condition on sex. Overall, second class survived much more than third (41% vs 25%) and the crew had the lowest rate (24%), yet among men second class did slightly worse than third (14% vs 17%) and male crew did better than both (22%). This is Simpson’s paradox: the marginal ranking is driven by how many women each group contained. Which one is relevant depends on the question being asked, and the χ² test alone cannot answer that.

Even the conditional association is not a causal effect. Class is a proxy for several mechanisms the data do not record: cabin location (the third-class accommodation was lower in the ship and further from the boat deck), physical barriers and the order in which crew directed people to the lifeboats, language barriers, family size and nationality. Each of these could link class and survival, and they cannot be separated with a two-way table.

7.2 Statistical association is not causality

  • What χ² measures. It compares the observed joint distribution with the one implied by independence. Rejecting H0 means the two variables are associated in the population, i.e. the conditional distribution of one changes with the other. The statistic is symmetric in X and F, so it carries no information about direction: “X → F”, “F → X” and “Z → X and Z → F” all produce the same table.
  • Why an association can be non-causal. (i) Confounding: a third variable affects both (sex and class above). (ii) Reverse causation: the direction may be the opposite of the one assumed. (iii) Selection bias: conditioning on how units entered the sample can create associations that do not exist in the population (collider bias). (iv) Chance: at α = 0.05, one test in twenty on truly independent variables rejects anyway, which matters when many tables are tested.
  • Significance is not strength. The p-value depends on n. With 200,000 records a negligible difference becomes “highly significant”, while a substantial one can be non-significant with 30 records. Report an effect size (Cramér’s V, differences between conditional proportions, odds ratios for 2×2 tables) alongside p.
  • Failing to reject is not proof of independence. A large p-value means the data are compatible with H0, not that H0 is true. The test may lack power, and χ² can miss dependence that is diluted across many cells or present only within strata.
  • What causal claims require. Randomisation (an experiment assigns X independently of everything else, so a remaining association can be attributed to X), or, with observational data, an explicit causal model (e.g. a DAG) plus adjustment for the confounders it identifies: stratification, Cochran–Mantel–Haenszel tests, log-linear or logistic models. Bradford Hill’s criteria (temporal order, dose–response, consistency, plausible mechanism) also support a causal reading. None of these can be read off a single contingency table.
